# Install in Claude Code

1. Open Claude Code and run `/plugin`.
2. Go to Discover, find `caveman`, `ponytail`, `design` and `obsidian-notes`, and install each one.
3. Built-in skills (docx, xlsx, pptx, pdf, docs, deep-research, skill-creator, google-workspace) come with your subscription. Nothing to install.
4. Connectors: claude.ai, Settings, Connectors. Connect Gmail, Google Drive, Figma, Brevo, Netlify, Firecrawl and GitHub with your own accounts.
5. Restart Claude Code. Run `/plugin` to check that all four plugins are enabled.

Never copy `~/.claude/.credentials.json` or `~/.claude.json` from anyone.
