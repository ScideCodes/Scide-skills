# My Claude Code setup

Open `/plugin` in Claude Code to browse and install.

## Plugins
- caveman: terse replies, fewer tokens
- ponytail: smallest-change coding mode
- design: critique, handoff, a11y, UX copy
- obsidian-notes: markdown vault linting and indexing

## Skills (Anthropic built-ins, already included with your subscription)
docx, xlsx, pptx, pdf, docs, deep-research, skill-creator, google-workspace

## Connectors (connect your own accounts at claude.ai, Settings, Connectors)
Gmail, Google Drive, Figma, Brevo, Netlify, Firecrawl, GitHub

No keys, tokens or account details are in this repo.

## Install

- Claude Code: see [INSTALL-CLAUDE.md](INSTALL-CLAUDE.md)
- Codex: paste the prompt in [INSTALL-CODEX.md](INSTALL-CODEX.md) into Codex
